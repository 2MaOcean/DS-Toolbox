## 核心模块
- **下载中心**：五家网盘直链解析、自适应并发、断点续传、限速、aria2 导入、BT 种子。
- **文件管理**：双栏浏览、跨栏拖拽、搜索排序、ZIP 流式打包、文本/plist/JSON 编辑、SHA256、格式转换。
- **内置浏览器**：多标签、书签、历史、Cookie 捕获，支持网页内拦截下载直链。
- **TS 工具**：基础监控、网络工具、描述文件生成。*(勾选协议后解锁：应用管理、JIT、越狱调度、IPA 安装等)*。
